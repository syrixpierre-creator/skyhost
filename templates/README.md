# SKYHOST starters

Source code deployed by the templates of the dashboard (Templates page). Each folder is a complete app that
SmartDeploy builds without configuration. Set `SKYHOST_TEMPLATES_REPO` to use your own copy.

| Folder | Template |
| --- | --- |
| `nextjs-postgres` | Next.js + PostgreSQL |
| `express-redis` | Express API + Redis |
| `whatsapp-bot` | WhatsApp bot (worker) |
| `vite-react` | Static site (Vite + React) |
